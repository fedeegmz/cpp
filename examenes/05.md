## Algoritmos

### 1.

En un supermercado se desea crear un algoritmo para calcular el descuento a los clientes.

El cliente ingresa el monto total de la compra y el tipo de pago, según este tipo se le realizará un descuento. Compra en débito 10% de descuento, compra en crédito 15% de descuento.

Mostrar la siguiente salida por cada cliente.

```
Total de las ventas: 2500$
Descuento: 250$
Total a pagar: 2250$
```

### 2.

Realizar un algoritmo para calcular y mostrar el salario de N vendedores.

El salario se calcula a partir de un sueldo base de 1.500.000$ más el 5% del monto de las ventas del mes. Debe ir ingresando la cantidad de ventas de cada empleado, e ir sumando todas las ventas que hizo en el mes.

Mostrar la siguiente salida por vendedor.

```
Total de las ventas mensuales: 300000$
Aumento: 15000$
Salario Total: 1515000$
```

### 3.

Diseñar el algoritmo para generar la siguiente salida. Donde N ingresa por teclado.

```
N=5
11111
22222
33333
44444
55555
```

## Trazas

**Traza 1**

```cpp
#include<iostream>
using namespace std;

int main(){
    int contUno=2, contDos=3, aux;

    do{
        contUno++;
        contDos+=2;
        aux = contUno + contDos;
        if (aux % 2 == 0){
            cout<<"Si\n";
        } else cout<<"No\n";
    } while (contUno < 10);
}
```

**Traza 2**

```cpp
#include<iostream>
using namespace std;

int main(){
    int cont=10, suma=0;
    while (cont>2){
        switch (cont){
            case 10: case 4: case 5:
                suma-=5;
                break;

            case 7: case 8: case 3:
                suma+=20;
                break;

            default:
                suma+=5;
        }
        cont--;
    }
    cout<<"La suma es "<<suma;
}
```
