**Traza 1**

```cpp
#include<iostream>
using namespace std;
int main(){
    float descuento, aumento, salario;

    cout<<"Bienvenido al examen\n";
    salario=1500;

    if (salario<1500){
        cout<<"Camino A\n";
        descuento=salario*0.05;
    } else if (salario>1500 && salario<=2000){
        cout<<"Camino B\n";
        descuento=salario*0.10;
    } else {
        cout<<"Camino C\n";
        descuento=salario*0.15;
    }

    salario=salario-descuento;

    if (salario<1500){
        cout<<"Camino A\n";
        aumento=salario*0.05;
    } else if (salario>=1500 && salario<=2000){
        cout<<"Camino B\n";
        aumento=salario*0.10;
    } else {
        cout<<"Camino C\n";
        aumento=salario*0.15;
    }

    salario=salario+aumento;
    cout<<"Salario Final: "<<salario<<"$\n";
}
```

### 2.

Diseñe un algoritmo que calcule la nota final de la materia, e indique si el alumno está aprobado, debe rendir en POEC o febrero.

El programa debe ingresar la nota del examen, la nota del trabajo práctico y la cantidad de asistencias.

Debe calcular el promedio de la nota del examen y el trabajo práctico. La nota final es a partir:

- Si el promedio es 7 o más y además tiene una asistencia mayor a 15 clases, el alumno aprueba.
- Si el promedio es menor a 7 o mayor a 4 y tiene una asistencia mayor a 10 clases, el alumno debe rendir en POEC.
- Si no cumple ninguna de las condiciones el alumno debe rendir en febrero.

### 3.

Diseñe un algoritmo que calcule y muestre el salario final de un trabajador, ingresando las horas trabajadas, el valor de estas y la cantidad de hijos que tiene a cargo.

Debe calcular el salario base. A partir de este debe aplicarse un descuento:

- Si el salario base es menor a 150000, el descuento será del 20000$.
- Si el salario base está entre 150000 y 100000, el descuento será del 15000$.
- Si no cumple ninguna de las condiciones el descuento será del 5000$.

Debe calcular el aumento en base a la cantidad de hijos que tiene:

- Si tiene más de 4 hijos; se le dará un aumento de 8%.
- Si tiene entre 1 y 4 hijos; se le dará un aumento de 5%.
- Si no tiene hijos no tiene aumento.
