**Traza 1**

```cpp
#include<iostream>
using namespace std;
int main(){
    float descuento, aumento, salario;

    cout<<"Bienvenido al examen\n";
    salario=2000;

    if (salario<1500){
        cout<<"Camino A\n";
        descuento=salario*0.05;
    } else if (salario>1500 && salario<=2000){
        cout<<"Camino B\n";
        descuento=salario*0.10;
    } else {
        cout<<"Camino C\n";
        descuento=salario*0.15;
    }

    salario=salario-descuento;

    if (salario<1500){
        cout<<"Camino A\n";
        aumento=salario*0.05;
    } else if (salario>1500 && salario<=2000){
        cout<<"Camino B\n";
        aumento=salario*0.10;
    } else {
        cout<<"Camino C\n";
        aumento=salario*0.15;
    }

    salario=salario+aumento;
    cout<<"Salario Final: "<<salario<<"$\n";
}
```

### 2.

Diseñe un algoritmo que calcule y muestre el salario final de un trabajador, ingresando las horas trabajadas, el valor de estas y la cantidad de hijos que tiene a cargo.

Debe calcular el salario base. A partir de este y cantidad de hijos debe calcular un aumento:

- Si el salario base es menor a 150000, o tiene más de 3 hijos, el aumento será del 25%.
- Si el salario base está entre 150000 y 100000, o tiene más de 1 hijo, el aumento será del 20%.
- Si no cumple ninguna de las condiciones el aumento será del 15%.

### 3.

Diseñe un algoritmo que calcule y muestre el monto final de una compra, ingresando el precio del producto, la cantidad del mismo y el tipo de pago (débito o crédito).

Debe calcular el monto, a partir de este se calcula un descuento:

- Si el monto es mayor 15000, el descuento será del 15%.
- Si el monto está entre 15000 y 10000, el descuento será del 10%.
- Si no cumple ninguna de las condiciones el descuento será del 5%.

Debe calcular un segundo descuento, a partir del tipo de pago: si es en débito un descuento de 1500$ y si es en crédito un descuento de 1000$.
