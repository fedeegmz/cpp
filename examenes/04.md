## Algoritmos

### 1.

Leer un número N y una secuencia de números (N números). Mostrar la cantidad de números impares ingresados.

```
N= 8
Secuencia= 12, 22, 17, 33, 15, 46, 37, 31
Números impares ingresados: 5
```

### 2.

Realizar un algoritmo para calcular y mostrar el salario de N trabajadores.

El salario se calcula a partir de las horas trabajadas durante el mes (24 días), en estos 24 días trabaja diferentes horas por lo que deben ser ingresadas por teclado.

Se le paga 2250$ por hora.

Además, se le da un aumento del 25%.

Mostrar la siguiente salida por cada empleado.

```
Salario Base: 10000$
Aumento: 2500$
Salario Total: 12500$
```

### 3.

Diseñar el algoritmo para generar la siguiente salida. Donde N ingresa por teclado.

```
N=5
54321
54321
54321
54321
54321
```

## Trazas

**Traza 1**

```cpp
#include<iostream>
using namespace std;

int main(){
    int cont=3, suma=0;
    do{
        cont+=3;
        if (cont % 2 == 0){
            suma -= 5;
        } else if (cont % 3 == 0){
            suma += 10;
        }else{
            suma += 5;
        }
    } while(cont < 27);
    cout<<"La suma es "<<suma;
}
```

**Traza 2**

```cpp
#include<iostream>
using namespace std;

int main(){
    int contUno=10, contDos=2, aux;

    while(contUno > 1){
        aux = contDos + contUno;
        switch (aux){
            case 37: case 12: case 33:
                cout<<"A\n";
                break;

            case 48: case 42: case 20:
                cout<<"B\n";
                break;

            default:
                cout<<"C\n";
        }
        contUno--;
        contDos+=contUno;
    }
}
```
