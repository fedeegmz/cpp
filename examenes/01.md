## Práctica

### Resolución de problemas

1. La suma de tres números consecutivos excede en 10 unidades al doble del mayor de los tres. ¿Cuáles son esos números?
2. En una competición escolar participan 1500 niños de tres categorías: niños, infantiles y juveniles. Se sabe que los juveniles son el doble de los infantiles y que, sumados los niños e infantiles, hay 100 menos que juveniles. ¿Cuántos hay de cada categoría?

### Trazas

**Traza 1**

```cpp
#include<iostream>
using namespace std;
int main(){
    int cont,doble,acum=0;
    for(cont=1;cont<=10;cont++){
        doble=cont*2;
        if (doble<15){
            acum+=10;
        } else {
            acum+=1;
        }
    }
    cout<<"El valor final "<<acum;
}
```

**Traza 2**

```cpp
#include<iostream>
using namespace std;
int main(){
    int cont=0, acum=0;
    do{
        cont++;
        if (cont<5){
            acum+=10;
        } else {
            acum+=15;
        }
    } while(cont<10);
    cout<<"Valor final "<<acum;
}
```

### Algoritmos

1. Una empresa de seguridad desea implementar un programa para calcular los salarios de _N empleados_. El programa debe ir pidiendo las horas mensuales trabajadas por cada empleado y su puesto de trabajo; el valor de esta hora depende si es administrativo o técnico; las horas de técnico valen $21.000 y las administrativas valen $19.000.
   Mostrar el sueldo de cada empleado, y al finalizar mostrar cuántos empleados de cada puesto tiene la empresa.

2. En una tienda de ropa se desea utilizar un programa que vaya cargando la información de cada compra. Por cada compra se debe ingresar: monto de la compra y forma de pago (débito, efectivo o crédito). Si la compra es abonada en efectivo, se le hará un descuento al cliente de un 10%. Si la compra es realizada con débito, el monto no cambia. Si el cliente utiliza tarjeta de crédito, se le añade un recargo a la compra. Dicho recargo es de 3% del total. Mostrar por cada compra el total final a pagar. Se debe preguntar al usuario si desea cargar otra compra. Si ya no hay más clientes, el programa debe finalizar y mostrar la cantidad de personas que abonaron con efectivo. (utilizar estructura do while)
