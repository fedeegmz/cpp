## Práctica

### Resolución de problemas — Plantear y resolver en forma de ecuación.

1. La suma de tres números es 200. El mayor excede al del medio en 32, y al menor en 65, hallar los números.
2. Lorenzo gasta la mitad de su dinero en un videojuego, y la séptima parte en ir al cine. ¿Cuánto dinero tenía si aún le quedan 1500$?

### Trazas

**Traza 1**

```cpp
#include <iostream>
using namespace std;

int main(){
    int cont=0, aux=10;
    while(aux>=0){
        cont++;
        switch(cont){
            case 6: case 2: case 4:
                cout<<"A "<<endl;
            break;
            case 1: case 3: case 7:
                cout<<"B "<<endl;
            break;
            default:
                cout<<"C "<<endl;
        }
        aux=aux-2;
    }
}
```

**Traza 2**

```cpp
#include <iostream>
using namespace std;

int main(){
    int aux=10, acum=0;
    for (int cont=1; cont<=6; cont++){
        acum=acum+(aux*cont);
        aux+=10;
        if (acum<60){
            cout<<"Todavia es menor"<<endl;
        }
        else{
            cout<<"Ya es mayor"<<endl;
        }
    }
    cout<<"El valor final es: "<<acum;
}
```

## Algoritmos

### 1.

**a)** Se debe realizar un programa donde se ingresen las notas de inglés, matemática y programación de N alumnos y muestre:

- Promedio de cada alumno.
- Promedio general por materia.
- Cantidad de alumnos aprobados en programación (se aprueba con 7 o más).

**b)** Ingresar dos números a, b y retornar la cantidad de números múltiplos de 3 que hay entre ellos sin incluirlos.

### 2.

Se desea realizar un programa para un restaurante donde se registren 20 mesas atendidas. Por cada mesa se debe ingresar la cantidad de platos ordenados y el precio de cada plato de manera individual, para luego calcular el total a pagar. Además, se debe solicitar la forma de pago: efectivo, débito/transferencia o crédito. Si el cliente paga en efectivo, se aplica un descuento del 10%; si paga con débito o transferencia el total no se modifica; y si paga con crédito se aplica un recargo del 5%. El programa debe mostrar el total final a pagar por cada mesa. Al finalizar, informar el total de platos preparados y el total recaudado por las 20 mesas atendidas.
